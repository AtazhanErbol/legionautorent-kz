## Сравнение с сохранённой базой

Mobile до редизайна: главная 98 / LCP 2.329 с, автомобиль 99 / 2.179 с, каталог 99 / 2.103 с. После: главная 99 / 2.029 с, автомобиль 99 / 2.105 с (медиана трёх), каталог 99 / 2.029 с. Базового измерения города и desktop не было, поэтому улучшение относительно них не заявляется.
До последней оптимизации галереи карточка получила 98/98/99 и медиану LCP 2.330 с. Для существующего кадра 16:10 выбран уже готовый AVIF/WebP того же центрированного кадрирования, а второстепенным фото задан низкий приоритет. После оптимизации — 99/99/99, LCP [2180, 2105, 2104] мс; медиана 2.105 с. Все предыдущие замеры сохранены в before-gallery-optimization/. Остальные строки — один финальный запуск, исходная база — тоже один запуск, не медиана. Баллы mobile по каждому сопоставимому типу страницы не ниже исходных.

INP не измерялся: Lighthouse navigation сообщает TBT, а не полевой INP. Настоящий INP и CWV проверяются после публикации в CrUX/Search Console. SwiftShader использует CPU вместо физической видеокарты; desktop TBT главной отражает в том числе это ограничение. Отключать сцену ради лучшего балла не стали. Результаты локальной сети без production-аналитики не заменяют замер на сервере и реальном телефоне.

## Вес и сохранённая оптимизация

- Основной JS: 3 109 байт gzip; CSS ~7.8 КБ gzip, встроен в SSR без дополнительного блокирующего запроса.
- Three.js + сцена/loader + meshopt decoder: **149 303 байта gzip**, лимит <150 000 выполнен. Отдельный GSAP/ScrollTrigger: 42 294 байта.
- GLB 13 012 байт, постер 8 282; файлы и frontend/hero.js не менялись.
- Exo 2 + Golos Text: существующие self-hosted WOFF2 с Cyrillic/Kazakh; новые шрифты не добавлялись.
- Все автомобили остаются в серверном HTML; только первые 12 рисуются сразу с JS. Остальные раскрываются без запроса списка. content-visibility:auto, AVIF/WebP, размеры изображений и lazy loading сохранены. Без JS видны все машины.
- Карта запрашивается только по нажатию; аналитика только через отложенный GTM.

## Воспроизведение и файлы

`python tools/redesign_lighthouse.py` выполняет восемь последовательных запусков. Требуются готовая сборка, collectstatic, precompress, audit_server.py:8003 и native Nginx:8004; Docker в окружении отсутствует. Не запускать одновременно тяжёлые browser tests.

Финальные сырые отчёты: reports/redesign-lighthouse/*-{mobile,desktop}.json, сводка summary.json. Повторы карточки: car-mobile-run2.json / run3.json и car-mobile-repeat-summary.json. База: reports/visual-baseline/. Ранее снятые root Lighthouse JSON сохранены как история.

Docker build/up, боевой TLS, аналитика и полевой INP в этой проверке недоступны.
