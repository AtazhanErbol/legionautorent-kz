# Чистая копия проекта

Исходный каталог `D:\legionautorent.kz` сохранён. Чистая копия подготовлена отдельно, без сброса ветки и без удаления рабочей базы или фотографий оригинального проекта.

Сохранены действующие Django-приложения, модели и миграции, тесты, маршруты, шаблоны, используемые CSS/JS, шрифты, логотип, фавикон и новый комплект кадров баннера. Снимки исходного каталога нужны для повторяемого импорта и проверки URL; они оставлены.

Удалены из копии экспериментальные 3D-модели и рендереры, предыдущие видео баннера, неиспользуемые библиотеки и шрифты, промежуточные генераторы кода, многочисленные исторические отчёты и снимки экранов, ссылки на локальную виртуальную среду и инструкции отдельной сборки PythonAnywhere. Неиспользуемое приложение инвесторов не включено.

Не включаются в Git: `.env`, база, PostgreSQL cluster, учётные данные, заявки, `media/`, приватные резервные копии, `node_modules/`, `.venv/`, кэш, исследовательские референсы и результаты сборки. Производственные фотографии и данные передаются отдельным комплектом dump + media archive + manifest с контрольными суммами. Отдельно оставлен один публичный исходный файл 33 572 байта в `migration/test-fixtures/`: он необходим существующим тестам проверки импорта и не используется как новый баннер.

Миграции с прежними именами ресурсов и старые поля модели сохранены для безопасного восстановления действующей базы. Это история схемы; браузер не загружает из неё прежние ролики. Исторический URL `/video/video-2.mp4` также сохранён отдельно как рабочий URL старого сайта, а новый баннер использует только новую последовательность кадров.

Git-история сохраняется обычным продолжением `main`. Старые версии доступны в истории, а текущая рабочая версия содержит очищенный набор файлов. Изменение истории и принудительная перезапись не выполняются.
