# LEGIONAUTORENT

Сайт проката автомобилей на Django с PostgreSQL: каталог, страницы городов и автомобилей, заявки, RU/KZ/EN, SEO и собственная тёмная админка.

Это чистая копия действующего локального проекта. В репозитории находятся необходимые исходники, миграции базы, снимки старого каталога для импорта и новые кадры анимации. База, фотографии каталога, пароли и заявки переносятся отдельно закрытой резервной копией.

## Локальный запуск через Docker

```sh
docker compose -f docker-compose.dev.yml up --build -d --wait
docker compose -f docker-compose.dev.yml exec web python manage.py createsuperuser
```

Сайт: `http://127.0.0.1:8080/`. Админка: `http://127.0.0.1:8080/control-legion/`. Пустая установка не содержит действующей базы и фотографий: восстановите отдельно переданный комплект данных, как описано в инструкции. Не запускайте импорт поверх восстановленной рабочей базы.

## Структура

| Папка | Назначение |
|---|---|
| `legion/` | Настройки, маршруты и запуск Django |
| `cars/`, `locations/`, `pages/` | Автомобили, города и страницы |
| `core/` | Контент сайта, административная панель, общие функции |
| `bookings/`, `analytics/`, `seo/` | Заявки, события и SEO |
| `importer/`, `migration/` | Импорт и исходные снимки старого сайта |
| `templates/`, `frontend/`, `static/` | Интерфейс и используемые ресурсы |
| `deploy/` | Docker, Nginx, резервные копии и восстановление |
| `tools/`, `reports/`, `docs/` | Проверки, воспроизводимая сборка и инструкции |

Изображения автомобиля в баннере рисуются на canvas; заголовки, подписи и ссылки остаются HTML. Мобильные и настольные кадры загружаются постепенно, плеер не показывается. При отключённом JavaScript или reduced-motion доступен статический баннер.

Docker-конфигурация подготовлена и проверена по схеме и синтаксису Nginx. Реальная сборка контейнера и запуск на PS.kz требуют Docker и доступа к серверу; на исходном Windows-компьютере Docker отсутствовал.
