# SEO migration: Legion Auto Rent

Дата снимка: 2026-10-02. Источник: read-only HTTP crawl https://legionautorent.kz/ и существующего sitemap. Полные данные находятся в seo_audit_old_site.json и CSV, исходные страницы — migration/snapshot.

## URL и технологии

- Главная `/` одновременно является посадочной Астаны.
- Города: `/kostanay/`, `/ustkamenogorsk/`, `/pavlodar/`.
- Автомобили: `/car/<slug>` **без завершающего slash**, включая slug с `_` и временными суффиксами.
- Публичные признаки: nginx, PleskLin, PHP-подобная CSRF-форма с `_csrfToken`, jQuery 3, Slick, Fancybox. CakePHP вероятен по разметке CSRF, но без исходников это не подтверждено. Тип и структура БД неизвестны.
- Работающая старая форма отправляет имя, телефон, название авто на текущую страницу автомобиля. Новая версия сохраняет заявку менеджеру.
- robots разрешает весь сайт. Sitemap статический с lastmod 2024 года и содержит неработающие карточки с HTTP 500.

## Политика переноса

Все успешные legacy пути сохраняются побайтно. Django APPEND_SLASH=False. Модели хранят отдельный уникальный legacy_path; маршрутизация использует его, slug не регенерируется. Астана остаётся `/`.

Старые HTTP 500 не превращать в выдуманные карточки. Для них — настоящий 404 до восстановления данных из БД или подтверждённого индивидуального 301 на соответствующую карточку. CSV явно отмечает эти URL. Не делать массовый redirect на главную.

Canonical строится из SITE_URL и точного пути. Фильтры, сортировка, поиск и даты: noindex,follow + canonical базового каталога. Pagination noindex,follow; доступные карточки включены в sitemap. robots не блокирует фильтры, чтобы crawler видел noindex.

Скрытые автомобили, страницы и города исключены из sitemap и отдают 404. Redirect manager запрещает внешние назначения, циклы и цепочки. Sitemap использует реальные updated_at вместо произвольного lastmod.

## Контент и исправления

Сохранить непустые Title, Description, H1, основной текст и порядок галереи. Пустые метатеги заполнять по содержимому страницы. Исходные значения остаются в snapshot для сравнения.

Исправления требуют записи в отчёте: упоминание Астаны в Костанае и Усть-Каменогорске; публичные CMS-заглушки Павлодара; отсутствующие alt; пустые главные метатеги. Для городов добавляется отдельное полезное описание со ссылкой на соответствующий автопарк, без выдуманного адреса.

Не переносить устаревшее видео в критический путь. Не генерировать ratings/reviews/availability. Vehicle и AutoRental описывают только известные данные.

## Аналитика

Сохранить активные GTM-KJWPLLN, GA4 G-00P3VJTEK9, Яндекс.Метрика 92545653, verification meta. Старый закомментированный GTM не активировать. На staging/local сторонняя аналитика выключена. Проверить конфигурацию GTM перед production: неизвестно, дублирует ли контейнер прямые GA4/Метрику.

## Release gates

Импорт и сверка, все media, повторный crawl, тест POST с CSRF, проверка production noindex, backup/restore PostgreSQL/media, HTTPS, проверка analytics/debug событий и права Admin. Только после этого ручное переключение домена. Недостающие бизнес-условия, юридические тексты, подтверждение адреса Павлодара и источник 3D указаны в отчётах. Search Console/Webmaster требуют доступа владельца и выполняются после выпуска.
