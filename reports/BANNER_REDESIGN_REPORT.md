# Баннер Legion — 05.10.2026

Новый вариант установлен локально: http://127.0.0.1:8002/. Основа — предоставленный владельцем ролик `1219070a3e6a2412a79da8335f369b66.mp4`: движение главного объекта между композициями и смена текста. Музейная графика, белое кольцо, скульптура и шрифт референса не копировались.

## Что изменилось

- На первом экране заголовок расположен слева, автомобиль справа; прокрутка плавно переносит автомобиль влево, меняет ракурс, подпись и положение тонких световых линий. Нативная прокрутка работает в обе стороны; после сцены сразу начинается каталог.
- Сохранён утверждённый первый Mercedes. Для него подготовлена производная версия 60 fps с интерполяцией промежуточных кадров: 1440×810, 346 кадров, 5,767 с, **5 120 095 байт**, H.264, CRF 20, GOP 8, без B-кадров и звука, faststart. Это обработка исходного видео, а не новая генерация или новая 3D-модель. Исходник и прежний MP4 сохранены. Новых платных генераций нет.
- Контроллер больше не перематывает многократно на один кадр. Он отслеживает фактический показ декодированного кадра, затем выполняет следующую перемотку. Сглаживание учитывает время между обновлениями экрана.
- Полный автомобиль остаётся в кадре; проверены начало, промежуточные положения и окончание. Поиск и SEO-заголовок остаются серверным HTML. Существующие URL, SEO-поля, каталог и структура админки сохранены.
- На телефонах, низких экранах, при reduced-motion, экономии трафика и слабом устройстве используется статическая композиция. На узком экране доступна явная кнопка просмотра ролика. Для проверки сцены со скроллом нужно широкое окно не ниже 700 px.
- В CMS сохранён путь к исходному утверждённому ролику. Производная версия подставляется только для этого стандартного пути; другие загруженные владельцем видео обслуживаются без такой замены.

## Плавность: измерение показанных кадров

Один Chrome, 1440×900, восемь секунд прямой и обратной нативной прокрутки, без CPU throttling. Сравниваются прежний контроллер/MP4 из контрольной точки и новые; CSS-композиция одинакова. Измерение использует `requestVideoFrameCallback`, повторные уведомления об одном mediaTime исключены.

| Метрика | До | После |
|---|---:|---:|
| Средняя длительность перемотки | 11,64 мс | **1,25 мс** |
| 95-й процентиль интервала между показанными кадрами | 62,6 мс | **14,0 мс** |
| Максимальный интервал при движении в одном направлении | 76,5 мс | **27,8 мс** |
| Максимальный интервал, включая плавную остановку для смены направления | 125,0 мс | **83,3 мс** |

Пауза при смене направления связана со сглаживанием остановки. За тест показано 240/666 изменившихся кадров соответственно: 30/83,25 обновления за секунду теста. Последнее **не является частотой исходного видео**: при скролле время видео меняется быстрее реального, включая перемотку назад. Сам новый файл имеет 60 fps. Результаты относятся к этому компьютеру; реальные телефоны и Safari не проверялись. Полные данные: [banner_presentation_comparison.json](banner_presentation_comparison.json).
