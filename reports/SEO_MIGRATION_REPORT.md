До замены исходников создан Git checkpoint `d5e7e0a`, свежий custom PostgreSQL dump и архив media `20261002T195502Z`. SHA256 и восстановление подтверждены: 91 автомобиль, 4 города, 302 связи галереи. Первоначальная копия содержит 1500 медиафайлов. Новые AVIF/WebP и видео добавлены без удаления оригиналов. Миграции схемы добавляющие, существующие ID/таблицы сохранены.

Повторно использованы `migration/normalized.json`, `migration/media_manifest.json`, исходные HTML `migration/snapshot/`, `old-home.html`, первоначальные SEO CSV/JSON. Новый live/raw слой сохранён отдельно в `migration/rebuild/`; редактирование БД не использовалось как источник истины для SEO и slug.

## Казахский префикс

По требованию владельца сначала проверены существующие `/kz/`: каждый из 122 кандидатов непосредственно запрошен на live. Все дали 404, казахский текст не обнаружен, в полученных sitemap и внутренних ссылках префикс отсутствует. Поиск по публичному индексу не дал подтверждения казахских страниц, но закрытые Search Console/Yandex Webmaster недоступны: отсутствие индексации не считается доказанным.

Выбран `/kk/` для новых казахских страниц. `hreflang="kk"`, `<html lang="kk">`. `/kz/` остаётся 404, ни массового, ни поштучного редиректа на `/kk/` нет. Если владелец предоставит ранее не найденные рабочие `/kz/` адреса/снимки, решение следует пересмотреть до запуска.

RU без префикса, EN под `/en/`. Каждый HTML указывает ru/kk/en/x-default, x-default → соответствующая RU-страница. Canonical каждой языковой версии ведёт на неё саму; источник canonical override сохранён для RU. Переключатель открывает тот же автомобиль/город. Неполный перевод отображает RU fallback с noindex и не включается в sitemap. В sitemap alternates перечисляются только опубликованные полные переводы; в HTML полный языковой набор сохранён по прямому требованию ТЗ. До готовности переводов их присутствие в HTML не означает индексируемость.

## 27 старых ошибок 500

Все 27 адресов **повторно проверены**, и каждый всё ещё возвращал 500. Все присутствуют и в старом, и в заново полученном sitemap. В доступных успешно разобранных страницах внутренних ссылок на них не найдено (0); это не доказательство отсутствия ссылок на недоступных или не обнаруженных страницах.

Построчные данные и рекомендация: `legacy_500_recheck.csv`. Это конкретные модели/комплектации, поэтому нет оснований объявлять их мусором или безусловно перенаправлять на похожую машину. Основная рекомендация для каждого — восстановить оригинальный контент из БД/резервной копии владельца и вернуть 200 на точном пути. Пока данных нет — честная 404, исключение из нового sitemap. 500 не воспроизводится. 301 на главную, выдуманные карточки и 410 без доказательства окончательного удаления не применяются.

После получения данных: импорт по тому же legacy_path → проверка Title/description/H1/цен/медиа → 200 → добавление в sitemap. Если владелец докажет точную замену страницы, допускается один 301 на неё. Для подтверждённого окончательного удаления без замены — 404/410. До этого потеря этих 27 адресов остаётся открытым риском миграции.

## SEO-поля, тексты, цены

Для slug и SEO использован приоритет live HTML → первоначальный raw HTML → извлечённые данные. Непустые Title, description, H1, SEO-тексты и исходные OG сохранены. Исходные HTML-фрагменты хранятся в БД; при отображении небезопасный HTML очищается. Служебные тексты интерфейса полностью серверные, доступны без JS.

Выявлены **93 пустых meta description и 2 пустых Title**, в том числе оба поля главной; добавлены фактические подписи по городу/автомобилю/цене. Каждое заполнение записано в `import_report.json` как improvement. У главной H1 и заметка «Под режим такси и доставки авто не сдаем!» сохранены. SEO-текст «Прокат автомобилей в Астане» остался в HTML.

У трёх городских страниц исходный `og:url` ошибочно указывал главную. Он оставлен в legacy OG в соответствии с приоритетом raw-источника; canonical этих страниц корректный. Это зафиксированная особенность исходника, отдельное последующее изменение OG требует осознанного решения владельца.

`price_availability_diff.csv`: 91 строка сравнения; на момент итоговой сверки 0 расхождений цены и 0 расхождений публичности. Использованы публичные live цены. Наличие карточки не является календарём свободных дат; schema и интерфейс не обещают конкретную доступность. Тарифы, депозит, пробег и спецификации, которых нет в источнике, не выдумывались.

## Redirects и старые медиа

Перенаправлений сохранённых HTML-страниц **0**. Все 95 возвращают 200 непосредственно. 27 проблемных страниц и `/kz/` не имеют Location.

300 известных URL изображений из `migration/media_manifest.json` имеют одношаговый 301 на `/media/<original>`. Полный список соответствий содержится в этом manifest; конечные оригиналы сохранены локально. `/img/legionautorent.svg` и `/video/video-2.mp4?v=1.1` дают 200; видео сохранено с SHA256 в `migration/rebuild/legacy_video.json`. Неизвестные пути не допускают произвольного доступа к файлам.

Production Nginx подготовлен для одного 301 с HTTP/www на `https://legionautorent.kz` с тем же путём и query. Нативная проверка синтаксиса успешна; реальный TLS и внешние цепочки нужно проверить на сервере. Admin Redirect запрещает внешние цели, петли и цепочки; миграция не добавляет неподтверждённых соответствий.

## Sitemap, robots и структурированные данные

`/sitemap.xml` — индекс cities/cars/categories/pages. Секции содержат canonical URL, доступные переводы, x-default и lastmod моделей. Фильтры/поиск/сортировка имеют noindex и canonical базового списка. Черновики, формы, ошибки и скрытый каталог не включаются. Staging закрыт и meta robots, и X-Robots-Tag; production robots редактируется в CMS и содержит sitemap.

JSON-LD: WebSite, WebPage, AutoRental/LocalBusiness, Vehicle/Product с Offer в KZT и UnitPriceSpecification на день, FAQPage и BreadcrumbList. JSON проверяется автоматическими тестами и crawler. Название, телефон и адрес взяты из источника; geo/openingHours выводятся только при заполненных реальных значениях. На live координаты/часы не подтверждены, поэтому эти поля оставлены пустыми до ввода владельцем. Google Rich Results на публичном production ещё не запускался; наличие валидного JSON не гарантирует расширенный результат.
